# rufus4mac 0.4.0

A redesigned single-window workflow, an independent driver USB task, and a shared driver library
for new Windows installers.

## Three tasks, one window

- **Create bootable USB:** numbered setup cards, Windows ISO detection, optional driver bundles,
  and a fixed action/progress area.
- **Format USB:** explicit exFAT/FAT32 and GPT/MBR choices, with a preview of the actual drive name.
- **Add drivers:** copy installers to an existing mounted USB without formatting it. Existing model
  folders are kept; conflicts are reported instead of overwritten.

![New main screen](https://raw.githubusercontent.com/hulryung/rufus4mac/v0.4.0/docs/images/screenshot.png)

## Drivers ready when the PC cannot get online

The same driver library works in the new **Add drivers** task and under **Include drivers on this
USB** when creating Windows install media. Add installers from catalogs, local files/folders, or
direct links. Files go into `Drivers/<model>/`; run them on the Windows PC after installation.
They are not installed automatically or injected into Windows Setup.

Catalogs are shareable JSON files. The picker now searches model names, model numbers and catalog
names, with wrapping text and separate scroll areas for models and packages. Catalog downloads
are checked against the catalog's declared SHA-256. Invalid files and duplicate model names are
reported. The bundled Galaxy Book catalog provides Intel Wi-Fi drivers, not a complete driver suite.

## Other improvements

- Setup controls stay locked while checking an image or performing a task.
- The footer explains missing selections, insufficient space and required input.
- Copy complete MD5, SHA-1 and SHA-256 values with dedicated buttons.
- Image-read errors, local-account username validation, and post-task ejection guidance are clearer.
- The main app window is unique; reopening the app does not create a second main window.
- README rewritten around the three workflows, with four new screenshots, installation instructions,
  catalog guidance, troubleshooting and explicit limitations.

## Download and update

**macOS 13+ on Apple Silicon.** This DMG is arm64, including its bundled wimlib; it is not an Intel
Mac binary. Quit the old version, open `rufus4mac-0.4.0.dmg`, and replace RufusApp in Applications
using the included Applications shortcut. Launch the Applications copy after updating.

The app is Developer ID signed and the DMG is notarized and stapled. No separate Homebrew install
is needed. A SHA-256 sidecar file is attached alongside the DMG.

## Validation and limits

- **211 tests passed**, including synthetic-disk integration tests.
- Release signatures, Apple notarization, stapled ticket and Gatekeeper assessment passed.
- The mounted DMG's bundled wimlib was executed successfully.
- The signed app's task screens, catalog search and single main window were inspected.

Windows media targets UEFI. Driver inclusion during creation applies to Windows install media;
raw image layouts are preserved. The native WIM splitter remains experimental and off by default.
End-to-end boot and Windows installation on destination hardware remain manual validation tasks.
